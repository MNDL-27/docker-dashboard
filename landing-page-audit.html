Three steps to fleet visibility

01
Install the agent
One curl command per host. The agent runs as a systemd service, connects outbound, and uses ~12 MB of RAM.
02
See everything
Container state, CPU/memory/disk/network per host, live log streaming, Docker version and image digests.
03
Get alerted
Set thresholds for CPU, memory, disk, or container failures. Alerts fire in-app with email notifications coming soon.
